# 13-Week Rolling Cash Flow Forecast

## Overview
Developed a dynamic 13-week rolling cash flow forecast model to support liquidity planning, cash visibility, and short-term treasury decision-making. The model incorporates forecast tracking, variance analysis, and dashboard reporting.

## Key Features
- Rolling 13-week cash flow forecast
- Weekly cash inflow and outflow projections
- Cash balance tracking
- Variance analysis (Forecast vs Actual)
- AR aging integration
- Dashboard reporting and trend visualization
